## Admin

### Admin panel
The admin panel is hidden, meaning there is no GUI anchor tag leading to the panel. You'll need to access it through the URL, ending the URL with "admin-panel.html":
`http://localhost:3000/admin-panel.html`

Note: There is a bug where the edit and delete buttons may not show up despite being authenticated as an admin, refresh until they reappear.
